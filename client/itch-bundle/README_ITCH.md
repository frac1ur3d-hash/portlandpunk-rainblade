# Portland Protocol: Rain Blade — Itch.io Release Guide

## Fast Upload Steps (Under 2 Minutes)
1. Log into your account at https://itch.io and click **Upload New Project**.
2. Set **Title**: `Portland Protocol: Rain Blade`
3. Set **Classification**: `Games`
4. Set **Kind of project**: `HTML (You have an HTML game that can be played in the browser)`
5. Under **Uploads**:
   - Click **Upload files** and select `portland-rain-blade-itch.zip`
   - Check the checkbox: **[x] This file will be played in the browser**
6. Under **Embed options**:
   - Embed size: **1280 x 720** (Viewport is fluid and responsive)
   - Check **[x] Automatically start on page load**
   - Check **[x] Enable fullscreen button**
7. Under **Pricing**:
   - Select **$0 or donate** (Recommended: players can play for free, but passionate players can tip you $2 - $10!)
8. Under **Tags**:
   - `Cyberpunk`, `Action RPG`, `Hack and Slash`, `Loot`, `Pixel Art`, `Top-Down`, `Diablo-like`
9. Save and set Visibility to **Public**!
